# Cursor Bottom - Obsidian Plugin

[中文](#obsidian-光标到底部插件) | [English](#cursor-bottom---obsidian-plugin)

A simple Obsidian plugin that lets you move the cursor to the bottom of the document with a single shortcut.

## Features

- Adds a command that can be invoked via command palette or custom hotkey
- Move your editor's cursor to the bottom of the document with a single action

## Installation

### Manual Installation

1. Download the latest release
2. Extract the files to your `<vault>/.obsidian/plugins/cursor-bottom/` directory
3. Enable the plugin in Obsidian

## Usage

1. Search for "Move cursor to bottom" in the command palette
2. Or set up a convenient hotkey combination in Settings > Hotkeys

# Obsidian 光标到底部插件

[中文](#obsidian-光标到底部插件) | [English](#cursor-bottom---obsidian-plugin)

这是一个简单的 Obsidian 插件，提供一键移动光标到文档底部的功能。

## 功能

- 添加一个命令，可以通过命令面板或自定义快捷键调用
- 一键将编辑器光标移动到文档的最底部

## 安装方法

### 手动安装

1. 下载最新的 release
2. 解压文件到 `<vault>/.obsidian/plugins/cursor-bottom/` 目录下
3. 在 Obsidian 中启用插件

## 使用方法

1. 在命令面板中搜索"移动光标到文档底部"
2. 或者在设置 > 快捷键中为该命令设置一个方便的快捷键组合
